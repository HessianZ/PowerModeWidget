# 开发计划

## 目标与边界

完成一个免费的、明显的三态 Windows 11 桌面小组件，切换系统“电源模式”。v0.4.0 将界面缩为一排三个按钮，默认 192 × 42 DIPs，宽度不超过系统桌面三个图标横排的宽度。界面由 Explorer 桌面拥有，作为不置顶的小窗口显示，不显示任务栏图标，普通应用窗口可以遮住它。

采用 C# / WPF / .NET Framework 4.8 和 Windows 原生电源 API，不引入第三方运行依赖。开发使用 .NET 10 SDK 与 4.8 Developer Pack；运行使用 Windows 11 内置 4.8 / 4.8.1，无需下载 .NET 10 运行时。仅发布 win-x64 小体积便携包。提供桌面 owner 关联、边框/空隙拖动、状态同步和错误反馈；界面没有标题、常驻状态行或关闭按钮，使用右键菜单退出。不加入置顶开关、托盘、开机自启、计划任务或额外电源计划管理。桌面 owner 查找使用 Explorer 内部窗口结构；不支持的桌面宿主应明确报错并退出。

## 多 Agent 分工

- 主 Agent：统筹需求、集成、构建、真实设备验收、Git 与 GitHub 发布。
- 应用 Agent：WPF 三态界面、窗口交互和状态同步。
- API/测试 Agent：原生模式读写、切换验证、离线与真实 API 测试。
- 文档/发布 Agent：说明文档、验收计划、MIT 许可证和官方 GitHub Actions 工作流。

## 迭代与验收

1. 确认 Windows API 与最小依赖方案 → 验证：可以读取当前模式，三个模式标识与 Windows 设置一致。
2. 实现模式服务和离线测试 → 验证：模式映射、错误处理、读回验证和状态同步逻辑通过测试。
3. 实现紧凑桌面小组件 → 验证：一排三个按钮清晰可见、高亮与系统当前模式一致、宽度满足三图标上限，边框/空隙可拖动，右键菜单可退出；桌面 owner 行为保持正常。
4. 集成并生成便携包 → 验证：Release 构建和离线测试通过，新的打包目录仅包含 EXE、EXE.config、README 与 LICENSE；使用 Windows 11 内置框架，不携带运行时。
5. 真实设备验证 → 验证：记录初始模式，切换三种模式并读取系统值确认，最后恢复初始模式；外部切换能够同步；视觉检查界面。
6. GitHub 发布 → 验证：更新公开 HessianZ/PowerModeWidget 仓库、提交并推送代码、CI 成功、v0.4.0 Release 可下载。
