# 开发计划

## 目标与边界

完成一个免费的、明显的三态 Windows 11 桌面小组件，切换系统“电源模式”。v0.2.0 将界面附着到 Explorer 桌面，不显示任务栏图标，普通应用窗口可以遮住它，并更新公开仓库与可直接运行的下载包。

采用 C# / WPF / .NET 10 和 Windows 原生电源 API，不引入第三方运行依赖。仅发布 win-x64。提供桌面附着、拖动、状态同步和错误反馈；不加入置顶开关、托盘、开机自启、计划任务或额外电源计划管理。桌面附着使用 Explorer 内部窗口结构；不支持的桌面宿主应明确报错并退出。

## 多 Agent 分工

- 主 Agent：统筹需求、集成、构建、真实设备验收、Git 与 GitHub 发布。
- 应用 Agent：WPF 三态界面、窗口交互和状态同步。
- API/测试 Agent：原生模式读写、切换验证、离线与真实 API 测试。
- 文档/发布 Agent：说明文档、验收计划、MIT 许可证和官方 GitHub Actions 工作流。

## 迭代与验收

1. 确认 Windows API 与最小依赖方案 → 验证：可以读取当前模式，三个模式标识与 Windows 设置一致。
2. 实现模式服务和离线测试 → 验证：模式映射、错误处理、读回验证和状态同步逻辑通过测试。
3. 实现桌面小组件 → 验证：三个按钮清晰可见、当前状态明显、可拖动、没有任务栏图标，普通窗口覆盖时位于其后，失败时有可理解的反馈。
4. 集成并生成自包含包 → 验证：Release 构建和离线测试通过，发布包包含 EXE、README 与 LICENSE；不要求预装 .NET。
5. 真实设备验证 → 验证：记录初始模式，切换三种模式并读取系统值确认，最后恢复初始模式；外部切换能够同步；视觉检查界面。
6. GitHub 发布 → 验证：更新公开 HessianZ/PowerModeWidget 仓库、提交并推送代码、CI 成功、v0.2.0 Release 可下载。
